# Repository Context

## Project Name
Memory Game

## What this repo does
This repository contains a browser-based Memory (Concentration) card game built with plain HTML, CSS, and JavaScript. The game presents a grid of face-down cards, and the player flips cards to find matching pairs. The objective is to match all pairs with as few moves and as quickly as possible.

## Main features
- 4x4 and 6x6 board sizes
- Card flip animations
- Move counter
- Timer
- Star rating system
- Best-score tracking using browser local storage
- Keyboard accessibility support
- Responsive layout for different screen sizes
- No external dependencies or libraries

## What the project stands for
At a high level, the project is a small, self-contained front-end game demo that showcases:
- DOM manipulation in JavaScript
- CSS-based layout and animations
- browser state management with local storage
- accessibility best practices for interactive UI
- simple game logic in a lightweight web app

## How it is structured
